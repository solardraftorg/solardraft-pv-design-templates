<h2>🚀 About SolarDraft</h2>

<p><a href="https://solardraft.org"><b>SolarDraft</b></a> is an all-in-one web application bringing <b>3D rooftop solar layout design</b>, <b>hour-by-hour shading analysis</b>, <b>automated proposal building (PM Surya Ghar ready)</b>, and <b>lead management CRM</b> into a single platform.</p>

<p>By eliminating fragmented software stacks, SolarDraft enables solar professionals to generate client-ready proposals in under two minutes and streamline engineering workflows from lead capture to final installation.</p>
